# 리치아파트 대시보드 — 일일 데이터 업데이트 체크리스트

## 매일 받아야 하는 파일 (기흥구만)
1. 집셀 매물 엑셀 — 관리 중인 전체 단지 (아파트+오피스텔, 매매/전세/월세 다 한 파일에 섞여있음)
2. 국토부 실거래가 zip 4종: 아파트 매매, 오피스텔 매매, 아파트 전월세, 오피스텔 전월세

## 매일 올려야 하는 산출물 (index.html이랑 같은 폴더에 전부)
- `index.html`
- `listing_history.json` — 매물변동(SNAPSHOT_DIFF) 계산용 단순 스냅샷
- `listing_full_archive.json` — 상세정보(중개사·매물번호·특징문구) 포함 전체 보관함. **이게 있어야 대화가 바뀌어도 다음날 이어서 계산 가능.**

## 처리 순서 (스크립트)
1. `extract_all_deals.py <오늘_집셀_폴더> all_deals_오늘날짜.json`
   → 매매/전세/월세 전부 추출. 갭투자는 "특징" 문구 키워드(세안고·전세안고·갭투자·긴잔금·무주택·긴전세·임차인·명도불가·입주불가)로 판정, 가격은 대표+중복 매물 중 최고가 사용.
2. `build_sale_stats.py` — 매매 실거래(REAL, COMPLEX_STATS) 재계산. 동 단위 변동률도 반드시 포함.
3. `build_rent_stats.py` — 전월세 실거래(REAL_RENT) 재계산. 동 단위 변동률도 반드시 포함.
4. `build_new_tx.py` — 매매 "오늘 새로 올라온 실거래"(직전 파일과 비교)
5. (전월세도 같은 방식으로 새로 올라온 실거래 diff 필요 — 아직 전용 스크립트 없음, 수동 비교 중)
6. `update_archive_and_recompute.py` — listing_full_archive.json에 오늘 날짜 추가 + SNAPSHOT_DIFF/PERSIST_GONE 재계산

## ⚠️ 반드시 지킬 것 (이번에 실수했던 부분들)
- [ ] **모든 산출물에서 영통구 걸러내기** — 원본 집셀/국토부 파일엔 영통구가 섞여 올 수 있음(예: 9/8 배치). 추출 스크립트가 gu 필드로 구분은 해주지만, **병합할 때 "기흥구만" 필터를 빼먹기 쉬움**. 병합 스크립트 마지막에 항상 `gu=='영통구'` 개수를 세어 0인지 확인.
- [ ] **하나 고치면 같은 로직 쓰는 다른 곳도 같이 확인** — 예: 매매 동별 변동률을 고쳤으면 전세/월세도 똑같이 확인. dong 파싱 정규식을 고쳤으면 그 정규식 쓰는 다른 스크립트도 다 확인.
- [ ] **const를 통째로 교체할 때 앞뒤 다른 const를 실수로 지우지 않았는지** — 이번에 NEW_TX 교체하다가 RENT_DIFF가 통째로 날아간 적 있음. 교체 후 반드시 전체 const 목록(LISTINGS_ALL, REAL_RENT, REAL, COMPLEX_STATS, REAL_TX, EXISTING_MAX, NEW_TX, RENT_DIFF, NEW_RENT_TX, HAS_LISTING, APT_LISTINGS)이 다 파싱되는지 확인.
- [ ] **최종 저장 전 자동 스캔 필수** — 매매/전세/월세 × 아파트/오피스�텔 × 동 여러 개 × 탭 6개를 실제로 렌더링해서 "동동" 중복, NaN, undefined, null억, 빈 화면, 예외 발생 여부 확인.
- [ ] **DATA_LAST_UPDATED는 파일명 날짜로 수동 갱신** — 자동 계산 아님. 새 매매 zip 받으면 그 파일명 날짜로 코드에 직접 반영해야 함.

## 파일 저장 위치
작업은 대화가 끝나면 사라지므로, 위 스크립트들과 listing_full_archive.json은 **매번 사용자에게 파일로 전달**하고 깃허브에 올려두게 해서, 다음 세션에서 그 파일들을 다시 받아 이어갈 수 있게 한다.
